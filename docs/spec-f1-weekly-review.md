# F1 規格：週回顧

> 上游：[prd-directions-2026-09.md](prd-directions-2026-09.md) 第 4 節 F1、第 6 節假說
> 前置：F0 已上線（K 欄「跳過」）
> 狀態：規格 v1，可直接開發

---

## 1. 目的

在登記密度約 50% 的新水位下，逐日數字失去比較基準。週回顧把三個分數聚合成週趨勢，讓層 1（可見化）繼續有效。它同時是第 6 節假說的檢驗主體：**只上週回顧、不上提醒**，觀察登記比例會不會自己回升。

## 2. 資料依據（2026-09-06 從 CSV 統計）

| 週一起始 | 有分數天數 | 壓力平均 | 清晰平均 | 電量平均 |
|---|---|---|---|---|
| 06-22 | 7 | 4.1 | 5.6 | 4.6 |
| 06-29 | 7 | 4.6 | 5.6 | 5.1 |
| 07-06 | 2 | 3.5 | 6.0 | 3.5 |
| 07-13 | 3 | 4.0 | 5.0 | 3.7 |
| 07-20 | 3 | 3.7 | 5.0 | 3.3 |
| 07-27 | 4 | 5.0 | 6.8 | 5.0 |
| 08-03 | 4 | 5.5 | 5.5 | 5.0 |

| 08-17 | 4 | **6.8** | 6.2 | 3.8 |
| 08-24 | 5 | 5.2 | 5.8 | 4.4 |

兩個結論：
- 7、8 月每週有分數天數落在 2 到 5。**門檻設 2 筆**，所有週都畫得出來。
- 週平均讀得出東西。8/17 那週壓力 6.8，其他週 4 到 5。這是逐日刻度在 50% 密度下看不出來的。

## 3. 設計決策

| 決策 | 選擇 | 理由 |
|---|---|---|
| 週的定義 | 週一到週日，台灣時區 | 與 Sheet 側欄「週號」表一致 |
| 時間窗 | 最近 4 週，含本週（部分） | 夠看趨勢，不夠長到變成成績單 |
| 畫點門檻 | 該週有分數天數 ≥ 2 | 見第 2 節；1 筆不是週平均 |
| 跳過日 | 計入「有資料」，不計入平均 | F0 語意 |
| 位置 | 日期標題下方、心理狀態卡上方，常駐顯示 | 假說要求「看見」，不能藏在需要點開的地方 |
| 互動 | 無。不可點、不可展開、不可切換週數 | v1 只做看見 |
| Y 軸 | 固定 1 到 10，三個指標共用 | 避免自動縮放把小波動畫成大起伏 |
| 顏色 | 單色，沿用 `--accent` 與 `--text-muted` | C5：不上色警示、不分好壞 |
| 資料不足 | 整個區塊隱藏，不顯示任何文字 | 「資料不足」本身就是一種催促 |
| 文字回顧 | 包含，作為第二區塊「回聲」 | 見 3.1 |

### 3.1 為什麼包含文字回顧

[[能量日誌的個人改變機制]] 層 2 的迴圈是「讀前幾天的記錄 → 發現上週三反思寫『會議太多』→ 這週預先調整」。純數字圖表只完成迴圈的前半。顯示一句過去的反思或感恩，成本極低，卻是把「圖表」變成「回顧」的關鍵。

限制：7、8 月每週有文字的天數只有 0 到 4，所以取材窗要拉到 7 到 28 天前，且沒有素材時隱藏。

## 4. 版面

```
┌─────────────────────────────────────┐
│  2026年9月6日 星期日                  │
│  ✓ 已載入今日記錄                     │
├─────────────────────────────────────┤
│  這幾週                              │
│                                     │
│  壓力    ╲__╱‾   5.2                │
│  清晰    ‾‾╲_    5.8                │
│  電量    _╱‾╲    4.4                │
│                                     │
│  8/10   8/17   8/24   8/31          │
│  •••    ••••   •••••  ••○           │
│                                     │
│  ─────────────────────────────      │
│  8/28 · 反思                         │
│  「好久沒冥想了 輕量執行還是很舒服的」   │
└─────────────────────────────────────┘
│  心理狀態（既有）                      │
```

- 三條 sparkline，各佔一行，右側顯示**最近一個有點的週**的平均值，一位小數。
- 週標籤為該週週一的月/日。本週不特別標示「本週」，避免「本週還沒有點」的暗示。
- 資料密度列：每週一組小點。有分數的日子畫實心點，跳過的日子畫空心點，其他日子**不畫**。沒有分母、沒有數字。
- 回聲區塊：一則過去文字，標日期與欄位名。沒有素材時隱藏這一段，分隔線一併隱藏。

## 5. 資料層：Google Apps Script

### 5.1 新端點：區間讀取

`GET ?from=YYYY-MM-DD&to=YYYY-MM-DD`

- 區間上限 60 天，超過回錯誤。
- 一次讀 A 到 K 全表（約 200 列），在記憶體篩選。
- **只回傳「有資料」的列**。有資料定義：B、C、D 任一為數字，**或** K 為 TRUE。活動欄全 FALSE、文字為空的預填列不回傳。這同時繞開既有單日端點把預填列當 found:true 的問題。

回應格式：

```json
{ "success": true, "from": "2026-08-10", "to": "2026-09-06",
  "rows": [
    { "date": "2026-08-12", "壓力分數": 4, "思路清晰度": 7, "睡前電量": 3,
      "散步": false, "冥想": true, "重訓": true, "跑步": false,
      "輕量感恩": "", "反思": "", "跳過": false },
    { "date": "2026-09-02", "壓力分數": null, "思路清晰度": null, "睡前電量": null,
      "散步": true, "冥想": false, "重訓": false, "跑步": false,
      "輕量感恩": "", "反思": "", "跳過": true }
  ] }
```

### 5.2 路由

`doGet` 依參數分流：有 `from` 與 `to` 走區間；否則走既有單日邏輯。既有 `?date=` 行為不變。

### 5.3 不動的東西

- 不新增欄位、不改 Sheet。
- 不改 `doPost`。

## 6. 前端：`index.html`

### 6.1 載入

`init()` 中與 `loadTodayRecord()` **並行**發出區間請求。`to` 為今天，`from` 為今天往前推到第 4 週的週一。兩個請求互不等待，週回顧慢到不會擋住表單。

### 6.2 聚合

```
for 每週 (週一起始, 4 週):
  scoredDays = rows in week where 壓力分數 is number
  skipDays   = rows in week where 跳過 === true
  avg[metric] = scoredDays.length >= 2 ? mean(metric over scoredDays) : null
  density = { scored: scoredDays.length, skipped: skipDays.length }
```

### 6.3 顯示條件

- 至少 **2 週** `avg` 非 null，才顯示 sparkline 區塊。否則整個 `#weeklyReview` 加 `hidden`。
- 回聲：從 7 到 28 天前的 rows 中挑 `反思` 或 `輕量感恩` 非空者。以當天日期為種子做確定性選取，同一天內重新整理不會換內容。沒有候選則隱藏。

### 6.4 繪製

- 內嵌 SVG，不引入任何函式庫。
- 每條 sparkline：viewBox 固定，X 為 4 週等距，Y 映射 1 到 10。`avg` 為 null 的週不畫點、線段在此中斷。
- 線與點用 `--accent`，週標籤與密度點用 `--text-muted`。
- 右側數值用 `.num` 既有樣式，字級小於滑桿數值。

### 6.5 錯誤處理

區間請求失敗：靜默隱藏區塊，`console.error` 記錄。**不**在畫面顯示錯誤，因為週回顧不是表單的一部分，失敗不應打斷登記。

### 6.6 狀態同步

送出一般記錄或跳過後，**不**重新拉區間資料、不即時更新圖。週回顧是「打開時看到的東西」，不是即時儀表板。下次打開自然更新。

## 7. 文案

| 位置 | 文案 |
|---|---|
| 區塊標題 | 這幾週 |
| 三個指標標籤 | 壓力、清晰、電量 |
| 回聲來源標示 | `M/D · 反思` 或 `M/D · 感恩` |

禁用：本週、達成、完成、%、連續、未登記、還沒、只有、資料不足。

## 8. 判準檢核

| 判準 | 本規格如何滿足 |
|---|---|
| C1 不呈現達成率 | 密度點無分母、無數字；隱藏而非提示資料不足 |
| C2 提醒不連續 | 不含提醒；`hidden` 狀態不帶任何文字 |
| C3 補登無欠債感 | 不標示缺漏日 |
| C4 跳過為正常資料 | 空心點與實心點並列，同色 |
| C5 只呈現趨勢 | 固定 Y 軸、單色、無閾值線、無好壞標示 |

## 9. 驗收條件

- [ ] `?from=&to=` 回傳只含有資料的列；預填空列不出現；跳過列出現且分數為 null。
- [ ] 區間超過 60 天回 `success:false`。
- [ ] `?date=` 既有行為不變。
- [ ] 以 7 到 8 月資料測試：每週都有點，8/17 週壓力點明顯高於前後週。
- [ ] 某週只有 1 筆分數：該週無點、線段中斷、密度點仍畫 1 個實心。
- [ ] 某週只有跳過：無點、密度點為空心。
- [ ] 最近 4 週不足 2 週有點：整個區塊 `hidden`，頁面無任何相關文字。
- [ ] 區間請求失敗或逾時：區塊 `hidden`，表單載入與送出不受影響。
- [ ] 回聲同一天內重新整理不換內容；7 到 28 天內無文字時隱藏。
- [ ] 送出後圖不變；重新整理後更新。
- [ ] 手機寬度下三條 sparkline 不溢出、不橫向捲動。
- [ ] 全頁搜尋不到第 7 節禁用字。

## 10. 觀察者側指標（不進前端）

這些只在 Phase 1 結束時由 Sheet 或 CSV 算，用來判斷 F3 要不要做。

| 指標 | 定義 |
|---|---|
| 有資料天數比例 | （有分數 + 跳過）/ 可登記天數，按週 |
| 對照基線 | 7 到 8 月的 52% |
| 判讀 | 上線 4 到 6 週後仍低於基線 → 進 F3 被動版；回升 → 不做 F3 |

⚠️ 9 月前 6 天為 0，會把 9 月月比例壓低。按週看，且從 F1 上線那週起算。

## 11. 範圍外

- 不做月回顧、不做自訂區間。
- 不做活動與分數的相關分析（例如「散步的日子壓力較低」）。那是層 2 的進階，樣本還不夠。
- 不做點擊某週跳到該週資料。
- 不做提醒。F3 另開。
- 不做補登。F2 另開，但 F2 上線後本規格的密度點自然會反映補登結果。

## 12. 開放問題

1. 回聲是否只取反思、不取感恩？感恩偏向情緒錨定，反思偏向可行動的觀察。層 2 迴圈用的是反思。**建議 v1 兩者都取，觀察哪一種讓人多看一眼。**
2. 週回顧放在表單上方，會不會讓每次打開都先「被評估」？固定 Y 軸與單色已降低這個風險，但要在上線一週後回頭問自己。若有壓迫感，備案是移到跳過按鈕下方。
